# رادار بايننس — 7 طبقات (احترافي)

تطبيق ويب للجوال يعمل على **GitHub Pages**، مبني حول فكرة **قائمة تحقق من 7 طبقات تأكيد** قبل الدخول، مع تبويب حيتان وتبويب خروج.

## التبويبات

| تبويب | الفائدة |
|--------|---------|
| **الفرص** | عملات وصلت لعدد طبقات كافٍ (مثلاً 5/7+) — مرشّحات دخول شراء |
| **الحيتان** | صفقات كبيرة حديثة (شراء/بيع) من AggTrades |
| **الطبقات** | تفصيل الطبقات السبع لعملة مختارة |
| **الخروج** | ضغط توزيع / ضعف بنية — لتجنب الشراء المتأخر |

## الطبقات السبع (تقريب عملي من بيانات Binance)

1. **اتجاه (Trend)** — EMA20 فوق EMA50 على 1س  
2. **زخم (Momentum)** — MACD histogram إيجابي/متسارع  
3. **حجم (Volume)** — حجم فوق متوسط 20  
4. **ضغط (Squeeze)** — ضيق نطاق ثم توسع  
5. **بنية (Structure)** — قمم/قيعان أعلى  
6. **تدفق ذكي (Smart)** — إغلاق قوي مع حجم  
7. **MTF** — محاذاة 4س / يومي  

> هذا تقريب تعليمي قابل للاستخدام على GitHub Pages بدون مفاتيح API. مؤشرات GrowthX الأصلية على TradingView أدق في بعض الطبقات الخاصة.

## كيف تستخدمه للدخول؟

1. امسح السوق.  
2. ركّز على **5/7 أو أعلى** في تبويب الفرص.  
3. راجع تبويب **الطبقات** للعملة.  
4. أكّد على الشارت (TradingView) + حجم الصفقة وحد الخسارة.  
5. تبويب الحيتان يدعم التأكيد؛ تبويب الخروج للتجنّب.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد لجذر المستودع.  
2. Settings → Pages → Deploy from branch → `main` / root.  
3. افتح `https://USERNAME.github.io/REPO/`.
