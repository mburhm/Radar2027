# رادار الخروج — استثمار 1–3 أشهر

تطبيق ويب ثابت (يعمل على **GitHub Pages**) يكشف أزواج USDT على Binance التي تظهر عليها إشارات **خروج / توزيع المستثمرين** على أفق شهر أو ثلاثة أشهر.

## ماذا يفعل؟

1. يجلب كل أزواج `*USDT` ذات سيولة كافية من Binance (واجهة عامة، بدون مفتاح API).
2. يحلّل الشموع **اليومية** و**الأسبوعية**.
3. يرتّب العملات حسب درجة «الخروج» اعتماداً على:
   - توزيع بعد صعود (سعر قرب القمة + ضعف الحجم)
   - انكسار بنية / متوسطات (SMA20 / SMA50 / أسبوعي)
   - زخم هابط على الأفق المختار
   - تراجع المشاركة (حجم أسبوعي)
4. يعرض روابط سريعة لـ Binance و TradingView.

## التشغيل على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (أو إلى مجلد `/docs`).
3. من **Settings → Pages**:
   - Source: Deploy from a branch
   - Branch: `main` (أو `master`) و المجلد `/ (root)` أو `/docs`
4. افتح الرابط الذي يظهر (مثال: `https://USERNAME.github.io/REPO/`).

> التطبيق يعتمد على طلبات مباشرة من المتصفح إلى  
> `https://data-api.binance.vision` و `https://api.binance.com`  
> (تدعم CORS للاستخدام العام).

## الاستخدام المحلي

أي خادم ملفات ثابتة يكفي، مثلاً:

```bash
npx serve .
# أو
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الإعدادات

- **أفق الاستثمار**: شهر / ثلاثة أشهر (يبّدل نافذة التحليل).
- **حد السيولة**: يصفّي الأزواج ذات حجم تداول 24س أقل من الحد.
- **أوزان الإشارات**: من زر الإعدادات (توزيع، بنية، زخم، حجم).
- يمكن استبعاد BTC/ETH من قائمة «الخروج».

## ملاحظات مهمة

- هذه **أداة تحليل مساعدة** وليست نصيحة استثمارية.
- حدود معدل طلبات Binance قد تبطئ المسح إذا كان عدد الأزواج كبيراً؛ التطبيق يحدّ التزامن ويعيد المحاولة تلقائياً.
- لا يُخزَّن أي مفتاح API؛ كل البيانات عامة.
